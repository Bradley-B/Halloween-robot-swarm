Halloween Robot Swarm

Control the LED strips and matrices on all connected robots.

LED strip

Color applies to solid, pulse, and chase modes. Time between animation updates. Lower values speed up rainbow and chase. Length of a complete pulse cycle. Use a shorter frame interval for smooth animation.

Settings are sent when you click Apply. They reset to rainbow when a robot restarts.

Matrix animations

Each matrix plays its selection independently. Choose all matrices to give them the same animation.

Animations repeat until changed. Frame timing is built into each animation. Selections reset when a robot restarts.

Custom command
Use the subject your robots listen to.
